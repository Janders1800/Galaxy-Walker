Controls

Keyboard + Mouse

  • Click — pointer lock
  • Mouse — look
  • WASD — move / drive / fly
  • Shift — boost / sprint / rover boost
  • Space — jump / rover jump jets / up thrust
  • Ctrl — down thrust (fly)
  • Q / E — roll (fly)
  • F — take off
  • L — land nearest
  • V — deploy / enter / exit surface rover
  • R — respawn
  • M — toggle mini map
  • + / - — zoom mini map
  • G — galaxy map
  • P — toggle sun lights
  • Esc — close galaxy map

Gamepad

  • Left stick — move (walk/fly)
  • Right stick — look
  • A — jump (walk)
  • LB / RB — roll (fly)
  • LS (press left stick) — boost (fly) / sprint (walk)
  • LT / RT — down / up thrust (fly)
Note: some UI toggles are keyboard-only for now (map / warp UI).
